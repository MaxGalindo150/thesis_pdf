\section{Experimentos y Resultados}

Esta sección presenta la evaluación experimental de la estrategia de entrenamiento propuesta basada en redes duales con supervisión física. Los experimentos están diseñados para demostrar cómo esta metodología mejora el proceso de aprendizaje y conduce a soluciones más robustas, utilizando la reconstrucción fotoacústica como caso de estudio.

\subsection{Diseño Experimental}

\subsubsection{Conjunto de Datos}
Para la experimentación se utilizó un conjunto de datos sintético derivado de imágenes de vasos sanguíneos de retina. El procedimiento de generación de datos consistió en:

\begin{itemize}
    \item Selección de un dataset público de imágenes de retina con diferentes patrones vasculares
    \item Ampliación mediante técnicas de aumento de datos hasta obtener 13,000 muestras
    \item Generación de señales fotoacústicas correspondientes utilizando el modelo físico de espacio de estados propuesto por Lang et al. \cite{Lang2017}
\end{itemize}

Este enfoque permitió crear un conjunto de datos de entrenamiento suficientemente grande mientras se mantenía la consistencia física entre las imágenes y sus correspondientes señales fotoacústicas.

\subsubsection{Métricas de Evaluación}
Para evaluar comprehensivamente los diferentes aspectos de la estrategia de entrenamiento, se utilizaron las siguientes métricas:

\begin{itemize}
    \item \textbf{Métricas de calidad de reconstrucción:} MSE, MAE, NRMSE, PSNR, SSIM
    \item \textbf{Métricas de eficiencia de entrenamiento:} Curvas de convergencia, estabilidad del entrenamiento
    \item \textbf{Métricas de transferencia de conocimiento:} Análisis de la evolución de las diferentes componentes de pérdida
    \item \textbf{Análisis estadístico:} Pruebas de significancia (t pareada, Wilcoxon) y tamaño del efecto (d de Cohen)
\end{itemize}

\paragraph{Análisis Comparativo de Estabilidad}
Las dinámicas de aprendizaje de ambas redes revelan diferencias significativas:

\begin{itemize}
    \item \textbf{Red reconstructora:} Muestra una convergencia rápida y estable, con la pérdida disminuyendo de 0.015 a 0.0005 MSE en aproximadamente 80 épocas. La proximidad entre las curvas de entrenamiento y validación indica una excelente generalización.
    
    \item \textbf{Red supervisora:} Presenta mayor variabilidad en la convergencia, con fluctuaciones considerables en la curva de validación y una brecha persistente entre las pérdidas de entrenamiento y validación. Este comportamiento refleja la mayor complejidad inherente a modelar el proceso físico fotoacústico.
\end{itemize}

Esta diferencia en las dinámicas de entrenamiento subraya la asimetría fundamental entre los problemas directo e inverso en este dominio, y justifica el enfoque de entrenamiento dual propuesto.

    \caption{Evolución de las componentes de pérdida durante el fine-tuning completo. Obsérvese cómo la pérdida física inicialmente alta se reduce progresivamente mientras la red aprende a incorporar el conocimiento físico sin comprometer la calidad de reconstrucción directa.}
    \label{fig:finetuning_dynamics}
\end{figure}

La dinámica del fine-tuning revela un patrón de transferencia de conocimiento secuencial:

\begin{itemize}
    \item \textbf{Fase inicial (épocas 1-20):} Alta volatilidad en la pérdida física ($\sim$0.4-0.5) mientras la red comienza a incorporar las restricciones físicas, manteniendo estable la pérdida directa.
    
    \item \textbf{Fase de estabilización (épocas 20-60):} Reducción gradual y más estable de la pérdida física hasta $\sim$0.2, indicando que la red está aprendiendo a balancear las restricciones físicas con la calidad visual.
    
    \item \textbf{Fase de convergencia (épocas 60-100):} Estabilización de todas las componentes de pérdida, con la pérdida física convergiendo a $\sim$0.13, demostrando un equilibrio efectivo entre reconstrucción visual y consistencia física.
\end{itemize}

Este patrón de evolución demuestra cómo la estrategia de fine-tuning facilita una transferencia gradual y efectiva del conocimiento físico a la red reconstructora.

La eliminación del componente físico ($\lambda_{physical} = 0$) revela su papel fundamental en la estrategia de entrenamiento:

\begin{itemize}
    \item Sin la guía física, la pérdida estructural domina el proceso de aprendizaje, alcanzando picos aproximadamente 4 veces mayores que en el modelo completo
    \item El MSE aumenta en un 12.69\% y el PSNR disminuye en 0.62 dB respecto al modelo pre-entrenado
    \item Análisis estadístico confirma que este deterioro es significativo ($t = -11.9974$, $p < 0.001$)
    \item La morfología de las señales fotoacústicas reconstruidas muestra inconsistencias físicas evidentes [REFERENCIA A GRÁFICA PROPUESTA]
\end{itemize}

Estos resultados demuestran que la supervisión física actúa como un regularizador natural que guía la red hacia soluciones físicamente plausibles, previniendo el sobreajuste a características puramente visuales.

La ablación del componente estructural ($\lambda_{struct} = 0$) revela consecuencias dramáticas:

\begin{itemize}
    \item Un aumento inmediato y sustancial en la pérdida física (valores cercanos a 2.0 inicialmente)
    \item Una degradación del 307.08\% en MAE y una caída catastrófica en el SSIM (de 0.9658 a 0.6257)
    \item Pérdida de detalles finos y características estructurales en las imágenes reconstruidas, particularmente en zonas de alta frecuencia espacial [REFERENCIA A MAPA DE CALOR PROPUESTO]
    \item El tamaño del efecto extremadamente grande ($d$ de Cohen = 4.5827 para SSIM) confirma la importancia crítica de esta componente
\end{itemize}

Estos resultados demuestran que el componente estructural no solo mejora la calidad visual, sino que también facilita la incorporación efectiva del conocimiento físico al proporcionar restricciones complementarias que estabilizan el proceso de aprendizaje.
